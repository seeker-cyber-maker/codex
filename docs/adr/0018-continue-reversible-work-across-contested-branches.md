# Continue reversible work across contested branches

An Attestation Conflict does not stop unrelated work or force an arbitrary
winner: each material premise may own a labeled Conditional Work Branch whose
inputs, conclusions, and acceptance limits identify the contested claim. Those
branches may perform reversible research, implementation, and verification that
can help resolve the dispute, but a scoped Conflict Gate blocks publication,
promotion, destructive action, external authority, or a closure claim that
depends on selecting a winner. This preserves task continuation without
allowing speculative branch progress to become silent mainline authority.
