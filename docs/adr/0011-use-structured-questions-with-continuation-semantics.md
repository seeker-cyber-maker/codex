# Use structured questions with continuation semantics

Dream House exposes an OpenCode-style structured question action that routes an
exact precision question to the human owner, a preauthorized expert, or a
read-only council and records the response in project history. Precision
questions, decision gates, and blockers are distinct: an unanswered precision
question carries a recommended answer, declared working assumption, affected
scope, and continuation plan, so safe reversible work proceeds; only missing
authority or a consequential choice pauses work at its explicit boundary.
Repeated questions correlate instead of creating duplicate prompts, and all
question handling remains aimed at task continuation rather than conversational
stalling.
