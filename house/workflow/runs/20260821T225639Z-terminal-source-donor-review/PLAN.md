# Terminal Source Donor Review

## Objective

Inspect the official iTerm2, Warp, Wave, Ghostty, and kitty repositories for
small, reusable control-plane patterns that improve Codex Dream House without
turning the harness into a terminal-emulator rewrite.

## Scope

- Source and project documentation only.
- No terminal launches, configuration changes, dependency installs, or feature
  implementation.
- Classify each finding as adopt, defer, or reject.

## Acceptance

- Every promoted pattern has an official source link.
- Design-document claims are distinguished from implementation evidence.
- The report names the Dream House target and the smallest future test.
