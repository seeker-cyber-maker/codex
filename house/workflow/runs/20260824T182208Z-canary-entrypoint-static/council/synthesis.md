# Promotion council synthesis

Decision: **ACCEPT_SOURCE_ONLY_PROMOTION**.

The first blind local same-model round had two acceptances and one narrow
revision. The revision was evidence-based: the static test initially proved
macro occurrence but not that the conditional compilation region was exactly
the production `main`. The coordinator tightened that assertion, regenerated
the object and pure-test receipts, and the targeted adversarial recheck
accepted the correction.

Confirmed observations:

- parent and helper have real positive admission paths and typed refusals;
- five source files compile as non-executable objects with no forbidden
  undefined symbols;
- disposable codec and entrypoint tests pass with ad-hoc-only signatures;
- candidate linking/launch, identity signing, Keychain, network, canary,
  provider, and real-secret paths remain not attempted.

Claim ceiling: this is a source-only entrypoint/interface promotion. It does
not prove a candidate bundle, signing identity, App Sandbox enforcement,
parent/helper containment, inherited descriptors at runtime, canary secrecy,
or live execution safety.

Smallest next action: only a new sealed runtime-qualification plan may propose
candidate build or inspection. It must retain this source binding and obtain a
fresh operation-specific review.

Limitation: this is multi-agent same-model local corroboration, not independent
cross-provider validation.
