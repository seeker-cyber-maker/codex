# Handoff

## Accepted result

The Dream House route catalog exposes `daybreak-blue-personal` for a manual
picker. The automatic selector rejects it before ordinary eligibility scoring
with `manual_only:usage_pool_boundary_unknown`.

The catalog deliberately records `health: unverified`. No provider call,
credential read, dispatch, or quota inference occurred.

## Reopen trigger

Automatic admission remains prohibited until the usage pool is identified,
the lane is separately inference-qualified, and a new authorized policy change
adds accepted route capabilities, costs, privacy, health, and fallback rules.
