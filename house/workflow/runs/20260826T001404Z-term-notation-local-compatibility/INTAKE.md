# Intake: TERM notation local compatibility experiment

## Objective

Measure only whether six opaque, locally installed, static-runtime-compatible
variants can preserve a closed TERM notation record across five controlled
prompt conditions. This is not a worker qualification, dialect-adoption
decision, model ranking, training exercise, or authority test.

## Authority

The operator explicitly authorized this separately bounded offline output
collection on 2026-08-25. Local inference and receipt writes are allowed.
Provider calls, network, task/relay mutation, promotion, training, credential
access, and dashboard integration remain forbidden.

## Candidate selection

The roster is bound by opaque identifiers only. Selection used structural
completeness, static MLX load compatibility, a chat-template surface, and a
fixed resource budget; names are not scoring inputs. One structurally complete
candidate was excluded because static loading rejected its tensor layout.
